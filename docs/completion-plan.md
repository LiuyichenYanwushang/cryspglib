## 1. 最终交付是什么

给定母群、凝聚表示、ISOTROPY方向、明确的标签约定，以及另一个待分导表示，得到：
1. 唯一且可追溯的普通/磁子群记录、基变换、原点和嵌入证据；歧义须明确报出。
2. 全部目标不可约表示/共表示及重数，分清真正不可约目标与纯幺正共轭配对。
3. 可核验的字符/矩阵作用；磁路径保留反幺正作用、交织矩阵、等距与完整重建证据。
4. 已存储数据与构造目标的真实来源；没有权威映射的标签/官方方向串明确缺失，不伪造。
5. 一套覆盖普通、磁Γ、磁非Γ/full-star和spinor/双群的公开契约、示例、错误分类与全域审计。

沿用原始完成口径：运行时不调用官方iso，不新增数值序参量稳定子搜索；P6验证有来源的给定方向，
不是搜索任意向量。普通未冻结参数族/多参数k的实际缺口也须在P1清点，不能用73条线代表整个连续k空间；
属于原目标且尚未实现的支路列入P4的独立普通子任务，已有能力不重复实施。

“完成”必须同时满足功能、正确性、数据来源和交付四方面；关键数学路径缺失不能用
Unsupported包装后算完成。数学缺口、确实缺少官方数据、用户输入非法、算术未决分开统计。
普通官方字符串的来源空表可以交付“明确缺失+标签/索引替代”的完整契约，但不得宣称字符串全覆盖。
任意setting/normalizer的适用范围和完备性必须明确；有限枚举搜空不能冒充一般不存在性证明。
没有全项目百分比和未经测量的工期承诺；每阶段用实际清单和验收结果更新剩余量。

## 3. 阶段与依赖

主线：P0 → P1 → P2 → P3 → P4 → P5 → P6 → P7。
P1必须同时清点后面各阶段的数据前提；若某类非spinor Type-B没有真实见证，P3只交付可验证部分，

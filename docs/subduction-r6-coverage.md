## 0. 记号与口径

* 源：冻结 little 特征标表 `W_LITTLE_CHARACTERS`（73 个），方向 `v` 存在表内，
  波矢 `k(t) = t · v`，`t` 为有理参数；官方参数 `t = 1/4`
  （`OFFICIAL_LINE_PARAMETER`）。
* 臂：`A = { R^{-T} v }`（母群 data-Hall 旋转，按**精确相等**去重，`±` 是两条臂）。
* 折叠：`q_a(t) = T^T (t · a)`，`T` 为嵌入的精确仿射变换；`q ≡ 0` 模**子群倒格**
  即"折到子群 Γ"。
* 恒等重数 `content(t)`：子群恒等表示在 `subduce_line_at_parameter(..., t)` 分解里的
  重数（`LineSubduction::trivial_content()`）。
* 参数语义：`LineSubduction::parameter_kind()` 返回 `ParameterKind::LineIrrep` 或
  `ParameterKind::Formal`。对不同冻结方向臂 `a`，精确检查 `t·(a-v) ∈ L*_parent`；若有
  满足者，成功返回的是冻结线小群上的形式诱导，不是增强小群在该 k 点上的实际线 irrep 分导。
* **证据级别**（本报告每一行都必须落在其中一档）：
  `E1` 外部对照（官方程序输出）／`E2` 数学推导 + 独立重算（不依赖被测代码路径）／
  `E3` 仅内部一致（引擎自检：维数守恒、重构）／`E4` 不支持（显式错误）。

## 1. 可执行的命题

**命题 1（支持集是四分之一网格）**：对每个源与每个子群嵌入，
`{ t : ∃ a ∈ A, q_a(t) ≡ 0 } = (1/4)Z`（即 `t ∈ {0, 1/4, 1/2, 3/4} mod 1`）。
判据是纯有理算术：`q_a(t) ≡ 0` ⟺ 对子群格三个基矢 `l` 都有 `t · (a · T l) ∈ Z`，
故单个臂给出三个有理条件的**交**（有理解 `t ∈ g_a Z`），支持集是各臂点集的**并**，
可精确枚举。注意并集不能用"生成元取 lcm"来算（那是交集，会把某些行的 `t = 1/4`
错误地去掉），必须逐臂枚举点集后合并——example 的测试钉住了这一点。
**实测（5,756/5,756 行）**：每行的支持集恒为 `{0, 1/4, 1/2, 3/4}`（4 个点）；
在 18 个非网格点 `t = j/24`（`j ≢ 0 mod 6`）上，
`5,756 × 18 = 103,608` 个 (行, 参数) 组合里折到子群 Γ 的臂数**全为 0**。
级别：**E2**（推导 + 独立重算；与引擎的 `Lattice::contains` 判定一致）。

**命题 2（重数只在网格点可能非零）**：`content(t) > 0 ⇒ 有臂折到子群 Γ`
（恒等表示要求 `q ≡ 0`），所以 `t ∉ (1/4)Z` 时 `content(t) = 0`（非退化点）。
级别：**E2**（命题 1 + 一条已在 §16 记录的证明），引擎在抽样点上的一致（全部为 0）
只是佐证，不计入证据等级。

**命题 3（共轭与位移 oracle，按冻结表是实还是复分成两支）**：73/73 个冻结方向都是
母群倒格矢，故 `k(-1/4) = -k(1/4) (mod G*_parent)`，而 `3/4 = -1/4 + 1`、
`7/4 = -1/4 + 2` 是**共轭点再沿同一条线走整数个倒格步**。用哪条 oracle 取决于冻结
little 表：

* `t = -1/4`：纯粹的共轭点。表**实**（`D* = D`；除 SG 202/203/209/210 的
  `DT3`/`DT4` 对以外的全部源）时 `χ_{-k} = χ_k*`，子群恒等表示自共轭 ⇒
  `content(-1/4) = pinned`（同一个源）。
* `t = 3/4, 7/4`：共轭**再过 `n = 1, 2` 个倒格步**。按
  [subduction-conventions.md](subduction-conventions.md) §16 的 monodromy 契约，这
  一步把标签换成 `M_v^n(C(α))`，所以 oracle 是**该标签在 anchor 的 pinned**。由于
  pinned 频率在 monodromy 轨道上为常数（`tests/line_monodromy.rs` 的
  `the_pinned_frequencies_are_constant_on_monodromy_orbits` 对 816 条非平凡像逐条
  钉住），它**数值上等于伙伴源的 pinned**——这正是下面那句"oracle = 伙伴源 pinned"
  仍然成立的原因；但推导路径是 monodromy 不变性，不是"位移是恒等"。
* 表**复**（SG 209/210 的 `DT3`/`DT4`，共 188 行）：共轭把源换成伙伴，
  `conj(DT3 @ +1/4) = DT4 @ -1/4`，所以 oracle 是**同一 isotropy 记录里伙伴源的
  pinned 值**，不是它自己的。拿自己的 pinned 去比会得到假的缺口。
级别：**E2**（推导），两支都不需要官方程序即可判定；`t = -1/4` 是推导，
`3/4, 7/4` 的标签位移是推导 + 上面那条 816 条 pinned 不变性。

**命题 4（沿线倒格位移 = monodromy 位移）**：令 `K = Δ · v ∈ G*_parent`，且该 shift
的相位通过该线小群的精确逐对乘法检查；则 `t` 与 `t + Δ` 是**同一个 k 点**，但
**不一定是同一个冻结表标签**：
冻结字符是 `k = Γ` 处解出的 `D`，参数进入 Bloch 因子，位移乘上 reciprocal-shift twist
`Φ_{Δv}`，把标签送到 monodromy 像 `M_{Δv}(α)`。`monodromy` 精确检查倒格成员关系和
相位是否构成小群的一维特征标；逐向量固定是充分条件，但不必要。未通过时返回
`UnsupportedShift`，不套用简单相位公式。
正确形式是

```text
decompose(α, t + Δ) == decompose(M_{Δv}(α), t)     （逐块逐目标）
```

`monodromy(parent, K)` 也支持不平行于 `v` 的一般母群倒格移；那时它计算的是同一小群
上的字符扭曲，不是沿该源的参数位移。测试中的 SG 203 `K=(2,0,0)` 是这种跨线扭曲
见证；全表 219 个“源×倒格基矢”用例也只检验通用扭曲的适用性与复合关系，不计作沿线
输运。沿线的独立口径是 73 个源步进和 5,756 行完整分解比较。

而不是"同一个标签在两边相同"（R6.1 的过强读法，已撤销）。73/73 冻结源的沿线最小
倒格步长都是存储方向 `v` 本身（`d = gcd(coords_{G*}(v)) = 1`），像唯一；完整分解
输运在 5,756/5,756 行通过。特别地，`t = 5/4` 仍由全表审计独立钉住，字符层也逐行
成立（`χ(5/4, α) == χ(M_v(α), 1/4)`）。级别：**E2 + E3**（位移/标签推导；逐目标
与逐字符比较都在 example 与集成测试里运行，审计把 `t=5/4` 作为硬失败门禁）。

## 3. 每行/每参数的分档（能力 B 的交付形式）

对每一行（源 × 子群嵌入）与每一个参数 `t`，结论属于且只属于以下一档：

| 档 | 条件 | 结论 | 当前行数 |
|---|---|---|---|
| **A. 外部已验证** | `t = 1/4` | 完整分解 + 恒等重数 == pinned（官方输出） | 5,756 / 5,756 |
| **B. 沿线等价参数（monodromy 像）** | `(t - 1/4)·v ∈ G*_parent`；本表 73/73 个源的 `v` 都是沿线最小倒格步长 | 与 A 逐块逐目标相同，标签按相应 `M_{Δv}` 输运；通用跨线扭曲不属于此参数位移命题 | 5,756 / 5,756（primitive-step 集成测试 + `t=5/4` 全表审计） |
| **C. 网格外（非退化）** | `t ∉ (1/4)Z` 且 `t·v` 稳定子 == 冻结小群 | `content(t) = 0`（证明级） | 每行除 4 个点外全部 |
| **D. 共轭参数（实表，已闭合）** | `k(t) ≡ -k(1/4) (mod G*_parent)` 且冻结表实（`t = -1/4, 3/4, 7/4, …`） | oracle = 同源 pinned（`3/4, 7/4` 上由 monodromy 不变性支撑）；**0 重数不一致、0 错误** | 5,568 / 5,568 可比 |
| **D′. 共轭参数（复表，引擎正确）** | 同上但冻结表复（`DT3`/`DT4`） | oracle = 伙伴源 pinned，引擎**全部满足** | 188 / 5,756 |
| **E. 其他网格点/退化点** | `t = 0`、`t = 1/2`，或 `t·v` 的稳定子严格大于冻结小群 | 引擎返回**形式值**或显式错误；无外部对照，不作为结论 | 见 §2 |

**"任意 t 成立 / 仅特定 t 成立"**：pinned 行全部是正频率（构造使然），而
`content(t) = 0` 在网格外成立，所以**没有任何一行**是"任意 t 都等于 pinned"；
正确表述是"在网格外的非退化参数上恒为 0，在 `t ≡ 1/4 (mod 1)` 的等价类上等于
pinned 的完整分解（标签按 monodromy 位移）"。**已验证域**仍为逐源
`t ≡ 1/4 (mod 1)`：全表测得 `d=1`，没有更小的沿线倒格步长。一般 `t=3/4` 一类
只有在满足该源的倒格等价条件时才可按 monodromy 输运；否则它仍是无外部 oracle 的
共轭 coset 参数，不应一概归为等价位移。

**退化参数（D 档以外）**：`(稳定子阶, 冻结小群阶)` 直方图由 example 打印；典型如
`t = 0` 时稳定子是整个母群点群（如 192 对 16），此时引擎解的是"冻结小群表示诱导出
的形式表示"，**不是**该点上的线 irrep 分导（后者不存在）。成功结果现在携带
`ParameterKind::Formal`；其判据是存在不同方向臂 `a` 满足 `t·(a-v) ∈ L*_parent`，
而不是方向臂 `a` 与 `v` 自身倒格等价，也不是对 `t=0` 或 `1/2` 字面值特判。缺少目标
字符时仍返回原有错误，不以形式结果代替失败。全表 `--gate` 汇总恒等重数等数值检查，
不累计 `ParameterKind` 分布；永久标签断言目前是 SG 196 `DT1` 的双侧见证。

## 4. 已知缺口与边界（必须与结论一起引用）

1. **共轭/位移参数的缺口已闭合，且缺口的原因就是 R6.1 自己的规范波矢**（三阶段历史，
   勿再把中间阶段的数字当独立计数）：
   * **R6.1 阶段**：假设 `t` 与 `t + 1` 是同一个母群 irrep，为此把 `k` 约化进母群
     fundamental cell（`canonical_wave_vector`），并让审计比较同标签的 `5/4` 与 `1/4`。
   * **R6.2 阶段 1（`efe8abb`/`315e49`）**：translation-aware ledger 测出该假设过强，
     但当时的读法仍在**约化**波矢上：`t = 3/4` 上 58 行报非整数重数（fail-closed）、
     50 行违反空间群共轭律，字符层 223 行不共轭。这些数字是**规范波矢的产物**。
   * **R6.2 阶段 2（本轮）**：冻结表是 `k = Γ` 处解出的 `D`，参数进入 Bloch 因子，
     所以引擎必须用**原始** `k(t) = t·v`；一个参数步是**标签的 monodromy 位移**
   （`(k + K, α) ~ (k, M_K(α))`，`cryspglib::irrep::line_monodromy`；K 需倒格且被该线
   小群固定）。撤销约化后：
     `t = 1/4`、`3/4`、`5/4` 三个参数的 **hard failure = 0**（各 5,756 行），
     共轭律违反 = 0（ledger 独立复算），字符层 `χ(5/4, α) == χ(1/4, M_v(α))`
     全表 5,756/5,756 相等，共轭 oracle（实表与复表）0 不一致、0 错误。
   * **仍然成立的边界**：`t = 3/4` 一类参数上，冻结表不是该 k 点小群的表示，
     其数值**没有 oracle**；本表 73 个沿线最小倒格步长均为 v，故当前已验证域仍是
     `t ≡ 1/4 (mod 1)`。这不是任意三维 K 的输运证明；后者需要完整 gauge transport。
   复现：`line_transport_ledger --witnesses`（逐见证表）、
   `line_transport_ledger --batch 3/4`（全表 hard-failure/共轭律清点）与
   `line_transport_ledger 14453 SM1`（单行完整账本）。
2. **目标表示族边界**：一维 solver 的 `MAX_ORDER=8` 与当前三类高维投影表示构造器
   （§2）；高分母本身不再触发网格搜索拒绝。
3. **性能长尾**：一般参数单次调用最坏分钟级（§2），全表 × 任意多参数的逐点审计不可行；
   小分母 `3..12` 的 42 点已全表扫描，其余一般参数仍采用"支持集判定 + 抽样佐证"。
4. **非恒等目标**：官方 pinned 只有恒等频率，一般参数下的非 Γ 目标**没有任何外部
   对照**，只有引擎自检（维数守恒、逐代表元重构），属 E3。
5. **范围**：仅普通标量；spinor、磁共表示、非 73 源的其他参数化 k 都不在本报告内。
6. **冻结源帧扩展**：当前 73 个源都来自立方母群，ISOTROPY 的旋转矩阵与 Rust 的倒空间
   逆转置作用在该正交基上给出同一小群。加入非立方源时，必须同步修正并验证
   `scripts/freeze_w_little_characters.py` 的 little-group 选择约定。

## 4b. R6.5：精确参数域普查（2026-09-26）

R6.4 之前的域结论来自分母采样（42 个点）。R6.5 把它换成**精确划分**：对每个冻结源
和每个母群操作 `R`，`R` 在参数 `t` 进入 `k(t)` 稳定子的条件
`t·(R^{-T}v − v) ∈ L*_parent` 的解集是 `Q` 的一个子群，因此由**一个精确有理步长**
生成，`[0,1)` 内的例外参数是该步长的有限残类。实现：

级别与边界（措辞按实测收紧）：

* 网格交叉验证**不是**独立算法：它与枚举共用步长代数，只把最终谓词换成
  `Lattice::preserves`；它的作用是验证条件的几何与残类枚举。它**看不见错的帧**：
  把子群网格检查喂进父群倒格仍报 0 不符（第二轮审查的变异见证），把整个子群帧换成
  父群帧也仍 exit 0（第三轮审查）；它只在旋转**破坏格**时才报警——用父群旋转集合配
  子群格给 70,128/33,395,328 不符，但把同样的替换限制在 89 个 P 心子群上又是 0 不符。
  真正算术独立的是**格坐标映射**那条路线（上表第 3 行）；帧本身由**显式帧断言**保证
  （上表第 4 行），三者职责不重叠。
* 网格只取 1/24 与 1/120：分母不被步长整除的网格点会漏掉例外参数（decoy 见证：
  方向 `(7,0,0)`、步长 `1/7` 时 1/24 与 1/120 网格只命中 `t = 0`）。因此网格检查
  只能加强、不能替代枚举；本报告的域划分来自枚举本身，网格是它的对照。
* 非空转的清点（数字经三轮审查各自复算，第四轮给出最终口径）：母群网格 371,520 个谓词
  中，`t ∈ {0, 1/2}` 上共 **10,320 个 = 5,160 个 `t = 0` + 5,160 个 `t = 1/2`**。
  逐类拆开：`t = 0` 的 5,160 个预测恒真（对步长无信息）；`t = 1/2` 的 5,160 个里
  **682 个是 `w = 0`**（旋转本来就在 generic 稳定子里，谓词恒真、也与步长无关），
  **4,478 个依赖步长**（1,038 个预测真、3,440 个预测假）。所以可判错的谓词数是
  **4,478**（`t = 1/2` 上），不是 5,160 也不是 1,720。中间出现过三个错误版本
  （"2,076"、"6,880 恒真 + 1,720 可判错"、以及"5,160 全部依赖步长"），都已作废。
* **中心化扫描的前提是显式守卫的（第四轮审查）**：扫描先积分再套同余式，只在格含于
  `Z^3` 时完备，所以 `minimal_parameter_step` 现在先检查行是否整（否则
  `DomainCensusInconsistent`；`w = 0` 在检查之前就返回 `None`，因为零属于任何格）。
  同一轮补的 `every_space_group_reciprocal_lattice_is_integral_with_small_exponent`
  把两条前提都钉在 230/230 个空间群上：倒格行全整；**格指数 ∈ {1:149, 2:58, 3:7,
  4:16}**（4 恰好是 16 个 F 心空间群，P=1、A/B/C/I=2、R=3）；**商 `Z^3/L*` 的指数
  （exponent）∈ {1:149, 2:74, 3:7}**。扫描界 6 要覆盖的是后者（最小中心化倍数 `n`
  整除 exponent），不是前者。**出处更正（第五轮审查）**：错的口径只有两处，且两处措辞
  不同——本文件 `0c17232` 写的 "230 个空间群的中心化格指数最大为 3"，以及 `AGENTS.md`
  `84172f6` 把 exponent 表 `P=1 / A,B,C,I,F=2 / R=3` 当成"中心化格指数"（F 写成 2）。
  被 SG 22（F222，指数 4、exponent 2）证伪的是"格指数 ≤ 3"这一半；`minimal_parameter_step`
  的文档在 `e93686b` 之前没有这两条前提句，`e93686b` 提交信息里"三处都写了"是**过度
  声明**，以本条为准。分数行见证：`diag(1/2,1/2,1/2)` 配 `w = (1,0,0)` —— 中心化扫描
  返回 `DomainCensusInconsistent`，坐标路线返回 `1/2`；同一输入上**未加守卫**的扫描会
  返回 `1`（只留 `t = 0`），而模块内部的"命中都是最小者的倍数"自检**不会**触发，所以
  这条守卫是载重的，不是装饰。
* **子群帧控制的自指漏洞已补（第五轮审查）**：该轮审查者把 `reciprocal_lattice` 对单个
  空间群改坏（SG 38 → 另一个心、SG 38 → `Z^3`、SG 5 → `Z^3`），门禁**全部 exit 0 且
  计数逐字相同**——因为 `record.child_sg == embedding.subgroup_sg()` 之后，
  "重建的格"与"期望的格"是同一个函数同一个参数（`f(x) == f(x)`）；阳性对照
  （SG 38 → `6Z^3`）会以 54 条 probe error 失败，说明该函数确实在关键路径上。现在两个
  方向都补了控制：① `probe_record` 把**普查自己**算出的子群小余群阶（来自
  `child_candidates`，其格在函数内部由 `exact_primitive_basis` 直接构造）带到每个探针上，
  与用 `reciprocal_lattice(child_sg)` 重算的阶逐点比较；② 新的单元测试用每个空间群
  **自己的纯平移**（`strict_sg_hall_ops` 的恒等旋转操作）导出同余条件 `h·c ∈ Z`，并断言
  其条数等于格指数——两个都在 `Z^3` 里的格，包含关系加相同指数即为相等。A↔C 交换
  （指数都是 2，此前对所有控制不可见）由 `the_per_space_group_congruences_separate_a_from_c`
  钉住：A 心满足 `k+l` 偶、C 心满足 `h+k` 偶，两者互斥。**同一类漏洞的第二个值也补了
  控制**：`rotation_set` 在门禁里同样只与自身比较，把 SG 38 的旋转集合少一个元素的变异
  实测**门禁仍 exit 0、计数逐字相同**，只有新单元测试
  `every_space_group_rotation_set_is_its_stored_hall_settings` 报
  `SG 38 (Hall 185): rotation-set order`；该测试用 crate 自己的
  `SymmetryOps::from_hall_number(SG_DATA_HALL[sg])` 重建每个空间群的旋转集合（与
  `strict_sg_hall_ops` 走不同的数据入口），230/230 逐集合相等。残余（写在 example
  注释里）：同倒格同旋转集合的**兄弟空间群**（116 个子群中 109 个有）在普查里仍不可
  区分，且记录号一致性其实由 `SubgroupEmbedding::build` 的 `StaleIsotropyRecord` 保证，
  属于复述而非独立控制。
* `DomainCensusInconsistent` 的**五**个 `reason` 中**两个**可达且都有负例：新增的
  `"the centring scan requires a lattice contained in Z^3"`（第四轮的分数行见证），以及
  "无中心化倍数"——后者只在**非空间群格**上（`diag(7,7,7)` 的合成格会走到；230 个空间
  群的商指数最大为 3、扫描界为 6，永远命中）。其余三条（未清分母、最小者不整除、非正
  步长）是把步长代数改坏时才会触发的防御性守卫：fail-closed、没有负例，也不宣称有。
  `subduction.rs` 的变体文档在第五轮按此改写（此前仍写"四个、只有一个可达"）。
* 划分本身是 **E2（推导 + 两条相互独立的构造 + 网格对照）**。
* **域内射影类：已证明恒为平凡（M2，2026-09-26）**。此前的口径是"'域内每一点都可分解'
  仍是 E3，因为普查只证明小余群阶在域内恒定、**没有**证明射影 cocycle 类在域内恒定"——
  这一条现已由推导解决，结论比"类恒定"更强：**类在域内恒为单位类**。
  设 `P = {R : R^{-T} q1 = q1}`（**精确**固定折叠方向的那些旋转，即 `w_R = 0`）。
  域内 `q(t)` 的小余群恰为 `P`：`w_R ≠ 0` 的旋转只在孤立的例外参数上满足
  `t·w_R ∈ L*`。对 `R ∈ P`，因子系 `ω_s(R,S) = χ_{s q1}(λ_RS)` 的 cocycle 恒等式只用到
  `(R^T − I)q1 = 0`，因此对**每个实数** `s` 都成立；于是 `s ↦ [ω_s]` 是从可除群
  `(R,+)` 到**有限**群 `H²(P,U(1))` 的同态，而从可除群到有限群的同态必为平凡 ⇒
  `[ω_t] = 1` 对每个实数 `t` 成立。剩下的 `t` 依赖只有 **gauge**（解一个系数连续的线性
  系统）：目标目录 = `P` 的普通不可约表示经 gauge 扭曲，而重数是 `t` 的整值连续函数 ⇒
  在每个域区间上恒定。**撤回（2026-09-26 外部审查，已接受）**："**每域一个代表点足以覆盖
  整个域**"是错的——本模块的分区只由**参考**折叠方向生成，而报告的分解依赖整个星（每条臂
  自己的小余群、以及臂对合并）。见证：ordinal 10030（SG 196 `DT1` → #18）参考候选只有
  `{0,1/4,1/2,3/4}`，另一条臂却在 `t=1/8` 获得**非平凡**类的阶 4 小余群；ordinal 10038
  （SG 196 `DT1` → P1）所有子群小群恒平凡，臂却在 `t=1/8` 合并（`1/9`、`1/7` 六个一维块
  各重数 1，`1/8` 四个块重数 2,1,1,2）。完整 full-star 分区与在其上的重数验证见
  `AGENTS.md` §3b 的 R6.7 卡 3–6；分区完成前不得再引用"每域一个代表点"。非 coboundary 族
  只可能在**小余群**例外参数上出现，这一条仍成立。
  两条前提都在语料上核对：母群侧 341 个冻结小群操作**精确**固定各自方向
  （`every_frozen_little_group_fixes_its_whole_direction`，并断言 `parent_domain` 的
  `generic_order` 数的是同一个集合）；子群侧由门禁对每个 (记录,标号) 数 `w_R = 0` 的
  旋转并与 generic 采样处的子群阶比较。
  **被撤销的中间版本（留在案上）**：这一检查的第一版把前提写成"`w_R ∈ L*`"（成员资格）。
  在语料上它是**空条件**而不是"更弱但成立"：作用域围栏要求方向是倒格矢、而每个旋转保持
  该倒格，所以**每个**旋转都满足它（母群 2,580/2,580、子群 28,713/28,713）。它也不蕴含
  "`χ_{s q1}·λ` 对每个实数 `s` 都是因子系"：在那个旋转集合上 cocycle 恒等式在 51,804 个
  (对, `s`) 探针中失败 4,877 个，而在精确固定集合上 51,804/51,804 成立。此前引用的
  "24,430 条门禁 violation"**按描述不可复现**（按描述是 5,117 对），已撤销；见证
  `w = (0,4,0)`、步长 `1/4` 仍可复现。它同样不蕴含"`t·w_R ∈ L*` 对每个参数成立"（只在
  `t ∈ sZ` 上成立）。步长求解器也不能当前提：`w ∈ Z^3 \ L*` 也返回 `Some(1)`，此时约束
  恰好只在整数参数上成立、残类 `{0}` 是正确的。
  仍未闭合的：① 例外参数上（小余群更大）的类没有定理，只有逐点精确判定——`MAX_ORDER = 8`
  的目录对 1,980 个 (记录,参数) 探针（子群阶 12/16/24/48）返回空，而"空"同时意味着
  "超范围"与"非 coboundary"，需要阶无关的精确判定来区分（M2.2）；② 上面是**分解的数学**
  在域内恒定，引擎在域内的行为还需要一次细网格重算作为经验控制（M2.3）。因此本节现在写
  的是"域已被精确命名 + 域内类已证明平凡 + 域内重数由连续性恒定"，而不是"任意 rational
  `t` 已端到端跑通"。
* **阶无关的精确类判定与边界实测（M2.2，2026-09-26）**。`subduction_catalogue` 新增
  `LittleCoGroup::{multiplication_table, cocycle_is_a_coboundary, cohomologous_to}`，前者
  的判定完全独立于 `MAX_ORDER`：选一组生成元作变量，沿乘法把每个相位写成生成元变量的
  仿射式（`ψ_k = ψ_i + ψ_j − ω_ij`），再对每条"生成元 × 全体元素"的方程得到整系数系统
  `C x ≡ d (mod 1)`；该系统在实数模一下可解 ⟺ 每个**整系数 syzygy** `y`（`y^T C = 0`）
  满足 `y·d ∈ Z`（`Z^m` 中湮灭 `Im C + Z^m` 的特征标恰好是这些）。syzygy 的 `Z`-基由
  带跟踪矩阵的整数行消元（Bezout 合并）给出。`line_domain` 暴露
  `child_cocycle_is_a_coboundary(child_sg, folded, t)`（逐点）与
  `child_cocycles_are_cohomologous(child_sg, folded, t1, t2)`（类相等，即商 cocycle 是
  coboundary——这就是可计算的完全不变量）。
  验证：① 平凡 cocycle 与显式 coboundary（`ω = ∂ψ`）判为平凡且互相同调，手工的
  `D16 → D4` 截面 cocycle 判为非平凡且与平凡类不同调；② 在**语料**上与一维求解器交叉
  验证 ≥300 个共群（凡 `|P_q| ≤ MAX_ORDER` 处两者必须一致，且样本含非平凡实例）。
  门禁现在对每个探针计算类：**所有非子群例外参数的探针上类都必须平凡**（定理的直接
  检验，7,034 个 generic 探针全部通过）；子群例外参数上的边界普查（35,039 探针，0 错误）实测为——阶 4：**3,260 非平凡**、
  阶 8：**936 非平凡**、阶 16：**134 非平凡**，阶 1/2/3/6/12/24/48 全部平凡。结论：非平凡类
  **只**出现在例外参数上（与定理一致）。**撤回（同上）**：原先按 probe 口径统计的
  "292/44/4 需构造、（引擎存储/构造）合计 340 个构造的非平凡类探针"作废——cocycle 取自参考
  折叠点，而 `TargetClass::Constructed` 只表示"某个块含构造目标"，两者不在同一块上（见证
  ordinal 13688，SG 225 `SM1` → #134，`t=1/8`：非平凡阶 16 块全为 stored，构造目标属于别的
  块）。逐块重算为 **192 / 0 / 0**（旧口径撤销）；按完整分区对全部块的新清点见 R6.7 卡 4，

* **完整 full-star 分区（R6.7 卡 3，2026-09-26）**。`line_domain::full_star_partition` 把
  分区从参考方向扩到整个星：对每条折叠臂 `v_i = T^T(R_i^{-T} v)`、每个**有序**臂对 `(i, j)`
  与每个子群旋转 `R_H` 精确求解 `t(R_H^{-T} v_i − v_j) ∈ L*_H`（`i = j` 是小余群增强、

  的关系而**不是**边界。母群臂表由 `line_domain::arm_images` 提供、生产路径
  `decompose::line_arms` 委托它（同一份实现，不可能出现分区与引擎各有一套臂表）。
  实测（常驻回归 `the_full_star_partition_of_the_frozen_corpus_is_the_eighth_grid`，5,756 个

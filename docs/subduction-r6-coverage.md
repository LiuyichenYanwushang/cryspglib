# R6.2 覆盖报告：参数化 k 分导的参数族（普通标量）

本报告回答 R6 的**能力 B**：pinned `isotropy_w_subduce_*` 的 **5,756 行**
（1,006 条记录、73 个冻结源）在**整个参数族**上的行为，以及每条结论的证据级别。
它不重复 R6.0/R6.1 的输入输出契约（见
[subduction-conventions.md](subduction-conventions.md) §16），只给"哪个参数区间成立
什么、哪些点不支持、凭什么"。

**复现**（全部数字由仓库内 example 重算，判词与退出码可直接进 CI）：

```bash
CARGO_TARGET_DIR=$PWD/target cargo run --release -p cryspglib \
  --example line_family_coverage -- --gate --output target/r6_family.tsv
CARGO_TARGET_DIR=$PWD/target cargo test --release -p cryspglib --example line_family_coverage
```

## 0. 记号与口径

* 源：冻结 little 特征标表 `W_LITTLE_CHARACTERS`（73 个），方向 `v` 存在表内，
  波矢 `k(t) = t · v`，`t` 为有理参数；官方参数 `t = 1/4`
  （`OFFICIAL_LINE_PARAMETER`）。
* 臂：`A = { R^{-T} v }`（母群 data-Hall 旋转，按**精确相等**去重，`±` 是两条臂）。
* 折叠：`q_a(t) = T^T (t · a)`，`T` 为嵌入的精确仿射变换；`q ≡ 0` 模**子群倒格**
  即"折到子群 Γ"。
* 恒等重数 `content(t)`：子群恒等表示在 `subduce_line_at_parameter(..., t)` 分解里的
  重数（`LineSubduction::trivial_content()`）。
* **证据级别**（本报告每一行都必须落在其中一档）：
  `E1` 外部对照（官方程序输出）／`E2` 数学推导 + 独立重算（不依赖被测代码路径）／
  `E3` 仅内部一致（引擎自检：维数守恒、重构）／`E4` 不支持（显式错误）。

## 1. 可执行的命题

**命题 1（支持集是四分之一网格）**：对每个源与每个子群嵌入，
`{ t : ∃ a ∈ A, q_a(t) ≡ 0 } = (1/4)Z`（即 `t ∈ {0, 1/4, 1/2, 3/4} mod 1`）。
判据是纯有理算术：`q_a(t) ≡ 0` ⟺ 对子群格三个基矢 `l` 都有 `t · (a · T l) ∈ Z`，
故单个臂给出三个有理条件的**交**（有理解 `t ∈ g_a Z`），支持集是各臂点集的**并**，
可精确枚举。注意并集不能用"生成元取 lcm"来算（那是交集，会把某些行的 `t = 1/4`
错误地去掉），必须逐臂枚举点集后合并——example 的测试钉住了这一点。
**实测（5,756/5,756 行）**：每行的支持集恒为 `{0, 1/4, 1/2, 3/4}`（4 个点）；
在 18 个非网格点 `t = j/24`（`j ≢ 0 mod 6`）上，
`5,756 × 18 = 103,608` 个 (行, 参数) 组合里折到子群 Γ 的臂数**全为 0**。
级别：**E2**（推导 + 独立重算；与引擎的 `Lattice::contains` 判定一致）。

**命题 2（重数只在网格点可能非零）**：`content(t) > 0 ⇒ 有臂折到子群 Γ`
（恒等表示要求 `q ≡ 0`），所以 `t ∉ (1/4)Z` 时 `content(t) = 0`（非退化点）。
级别：**E2**（命题 1 + 一条已在 §16 记录的证明），引擎在抽样点上的一致（全部为 0）
只是佐证，不计入证据等级。

**命题 3（共轭 oracle）**：73/73 个冻结方向都是母群倒格矢，故
`k(3/4) ≡ k(-1/4) = -k(1/4) (mod G*_parent)`：`t = -1/4`、`3/4`、`7/4` 描述的是
`t = 1/4` 那个母群 irrep 的**共轭**。子群恒等表示自共轭，因此
`content(-1/4) = content(3/4) = content(7/4) = content(1/4) = pinned`。
级别：**E2**（推导），可用作内部 oracle，无需官方程序。

**命题 4（等价参数）**：`Δ · v ∈ G*_parent` 时 `t` 与 `t + Δ` 是同一个母群 irrep，
**逐块逐目标**的分解必须相同。对全部 5,756 行成立（`t = 5/4` 对 `t = 1/4`）。
级别：**E2 + E3**（等价性推导；逐目标比较在审计里作为硬失败门禁运行）。

## 2. 实测结果

| 参数 | 结论 | 实测 | 级别 |
|---|---|---|---|
| `t = 1/4`（官方） | 完整分解成功，恒等重数 == pinned | **5,756 / 5,756**，0 错误 | **E1**（pinned 频率来自官方 `SHOW FREQUENCY`；live oracle 逐行复核） |
| `t = 5/4` | 与 `t = 1/4` **逐块逐目标**相同 | **5,756 / 5,756**，0 不一致（审计 `w_parameter_shift`） | **E2** |
| `t = -1/4, 3/4, 7/4` | 共轭 oracle：应等于 pinned | **199 行重数不同、58 行显式错误**（三者计数相同） | **E2 反例 → 已知缺口，见 §4** |
| `t ∉ (1/4)Z` | `content(t) = 0` | 103,608 个 (行, 参数) 组合里 0 条臂折到 Γ；抽样的 231 行里引擎答案全为 0（4 行显式错误，fail-closed） | **E2** |
| `t = 1/2` | 另一个母群 irrep，无外部对照 | 2,822 行重数 ≠ pinned，58 行显式错误 | **E3**（仅内部一致；非退化点见 §3） |
| `t = 0` | `k = Γ`，冻结小群严格小于实际稳定子 | 2,918 行重数 ≠ pinned，0 错误 | **E3**（形式值，见 §3） |

支撑数据（`target/r6_family.tsv` 每行一条，由 `--output` 生成）：

* 每行的四个网格值 `(content(0), content(1/4), content(1/2), content(3/4))` 直方图
  由 example 打印；`content(1/4)` 分量永远等于 pinned（E1）。
* 参数分母上限：小余群非平凡时走网格搜索，绑定门禁 `MAX_GRID = 200_000`
  （另有 `MAX_ORDER = 6`、`MAX_WORK = 4_000_000`）。实测 ordinal 10030 `DT1`
  （`|P_q| = 2`）在 `t = 1/100000` 仍 `Ok`、`t ≥ 1/1000000` 起
  `MissingChildStarData`；超限**报错**，不返回部分结果。
* 性能：`t = 1/4` 走存储路径，全表 5,756 行约 11–14 s；一般参数（尤其大分母、
  非平凡小余群）单次调用可到 p99 ≈ 40 s、最大 53.6 s（reviewer C 实测，
  446 行 × `t = 1/97` 合计约 724 s）。因此本报告的**全表**逐行计算只覆盖网格点与
  廉价的支持集判定，一般参数的引擎答案按抽样复核（`1/25` 行）。

## 3. 每行/每参数的分档（能力 B 的交付形式）

对每一行（源 × 子群嵌入）与每一个参数 `t`，结论属于且只属于以下一档：

| 档 | 条件 | 结论 | 当前行数 |
|---|---|---|---|
| **A. 外部已验证** | `t = 1/4` | 完整分解 + 恒等重数 == pinned（官方输出） | 5,756 / 5,756 |
| **B. 等价参数（同 irrep）** | `(t - 1/4)·v ∈ G*_parent`（含 `t = 5/4, 9/4, …`） | 与 A **逐块逐目标**相同 | 5,756 / 5,756（审计门禁） |
| **C. 网格外（非退化）** | `t ∉ (1/4)Z` 且 `t·v` 稳定子 == 冻结小群 | `content(t) = 0`（证明级） | 每行除 4 个点外全部 |
| **D. 共轭参数（已知缺口）** | `k(t) ≡ -k(1/4) (mod G*_parent)`（`t = -1/4, 3/4, 7/4, …`） | 应为 pinned，实际 **199 行不一致 + 58 行报错** | 257 / 5,756 |
| **E. 其他网格点/退化点** | `t = 0`、`t = 1/2`，或 `t·v` 的稳定子严格大于冻结小群 | 引擎返回**形式值**或显式错误；无外部对照，不作为结论 | 见 §2 |

**"任意 t 成立 / 仅特定 t 成立"**：pinned 行全部是正频率（构造使然），而
`content(t) = 0` 在网格外成立，所以**没有任何一行**是"任意 t 都等于 pinned"；
正确表述是"在网格外的非退化参数上恒为 0，在 `t ≡ 1/4 (mod 1)` 的等价类上等于
pinned 的完整分解"。D 档是本报告发现的实现缺口，不是数学结论。

**退化参数（D 档以外）**：`(稳定子阶, 冻结小群阶)` 直方图由 example 打印；典型如
`t = 0` 时稳定子是整个母群点群（如 192 对 16），此时引擎解的是"冻结小群表示诱导出
的形式表示"，**不是**该点上的线 irrep 分导（后者不存在）。这类值必须按形式值读，
R6.2 不把它们写成物理结论。

## 4. 已知缺口与边界（必须与结论一起引用）

1. **共轭参数（257 行）**：`t = -1/4, 3/4, 7/4` 上 199 行给出与 pinned 不同的重数、
   58 行报非整数重数（fail-closed）。根因是**线源字符在规范代表元上的相位约定**
   不自洽：`t = 1/4` 与 `t = 5/4` 恰好落在同一个"正代表元"上所以全绿；一旦规范波矢
   落在共轭代表元（`-k(1/4)`），诱导字符不再满足共轭 oracle。注意这**不是**
   "重数为零"式的静默通过，而是"与可证明的期望值不符"，因此列为缺口而非边界。
   任何修复都必须以"199/58 → 0 且 A/B 档保持全绿"为验收；
   `examples/line_family_coverage.rs` 的常量 `CONJUGATE_GAP_CONTENT/ERRORS`
   与 `target/r6_family.tsv` 是这条缺口的记账处。
2. **参数分母上限**：`MAX_GRID` 等三道 fail-closed 门禁（§2）。
3. **性能长尾**：一般参数单次调用最坏分钟级（§2），全表 × 多参数的逐点审计不可行，
   这是把一般参数改为"支持集判定 + 抽样佐证"的原因。
4. **非恒等目标**：官方 pinned 只有恒等频率，一般参数下的非 Γ 目标**没有任何外部
   对照**，只有引擎自检（维数守恒、逐代表元重构），属 E3。
5. **范围**：仅普通标量；spinor、磁共表示、非 73 源的其他参数化 k 都不在本报告内。

## 5. 与 R6.1 验收的关系

R6.1 的审计（三门口禁）现在包含两条与参数族相关的硬失败门禁：
`w_scope`（恒等重数 == pinned，全 5,756 行）与 `w_parameter_shift`
（`t = 5/4` 与 `t = 1/4` 的**完整分解**逐块逐目标相同）。共轭参数缺口**不在**审计里
——它对官方参数没有影响，且当前实现确实不满足；它由本报告的 example 与测试记账。
